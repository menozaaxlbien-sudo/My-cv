## ✨ Key Features & Technical Highlights

- **Bespoke, Non-AI Aesthetic:** Custom editorial design layout inspired by modern developer portfolios with clean typography, refined spacing, and subtle micro-interactions.
- **Dark & Light Mode Switcher:** Dynamic theme toggle with smooth CSS variable transitions and persistent `localStorage` preference.
- **Printable Executive Resume Mode (`@media print`):** Clicking "Print / Save PDF" renders a clean, distraction-free document layout ready for submission to employers and instructors.
- **Copy-to-Clipboard with Toast Notifications:** One-click copying for email and phone numbers with visual confirmation toast.
- **Interactive Project Previews & Modal:** In-depth view into project architecture, role, and technologies used.
- **Fully Responsive Design:** Tested and optimized for mobile screens (375px+), tablets (768px), laptops (1024px), and desktop displays (1440px+).

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/menozaaxlbien-sudo/My-cv.git
   ```
2. Navigate into the project directory:
   ```bash
   cd My-cv
   ```
3. Open `index.html` in your favorite browser or use VS Code Live Server:
   ```bash
   npx serve .
   # or simply double-click index.html
   ```
